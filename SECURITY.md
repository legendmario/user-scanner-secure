# Política de Seguridad y Uso Ético

## Propósito del Proyecto
Este proyecto está diseñado exclusivamente para fines de **ciberseguridad defensiva, auditoría de huella digital personal (Self-OSINT) e investigación autorizada**.

## Reglas de Uso Responsable
1. **Autorización previa:** No ejecute escaneos contra individuos u organizaciones sin su explícito consentimiento por escrito.
2. **Cumplimiento de Términos de Servicio:** Respete las políticas y condiciones de servicio (ToS) de las plataformas consultadas.
3. **No hostigamiento / No doxing:** Queda estrictamente prohibido utilizar estas herramientas para persecución, hostigamiento, difamación o recolección maliciosa de información personal.
4. **Protección de Datos:** Las salidas de datos y reportes generados deben tratarse de acuerdo a la legislación aplicable de protección de datos (RGPD, LOPD, etc.).

## Reporte de Vulnerabilidades
Si detecta algún fallo de seguridad en este repositorio o en la implementación del wrapper, por favor abra un *Security Advisory* en GitHub o comuníquese de forma responsable.
